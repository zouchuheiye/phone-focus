# 宣传MV-02 · 给正事留一段时间

配合「去做正事」1.3.1的36秒竖屏宣传MV，1080×1920、30fps，H.264 MP4 + AAC立体声。米白/深绿/暖金色，新的原创120BPM轻电子纯音乐，无人声。

- 视频：`output/phone-focus-daily-mv-1080p.mp4`
- 封面：`output/cover.jpg`
- 原创配乐：`output/original-score.wav`
- 字幕：`output/captions.srt`；镜头/字幕已直接绘入画面，无需播放器加载。
- 分镜：`storyboard.json`；成片抽帧与参数证据：`qa/`。

主线：消息打断 → 双框数字选时 → 多段独立开关 → 时段之间正常使用 → 每天重复 → 回到眼前的事。演示上午09:00—12:00、下午14:00—18:00及夜间22:00—次日07:00；在开关演示关闭下午一段后将其恢复，再示意当天的自动切换，避免叙事矛盾。

画面由代码生成，与手机真实录像分开；全片标注“功能动画示意 · 非实机录屏”，时间切换段标注加速，片尾保留无障碍/闹钟/后台授权与可撤权退出说明，不承诺全机型兼容或绝对强制。没有修改或重新发布APK，没有二维码、联网安装或外部发布。

程序配乐、几何图形与动画为原创；复用本项目上一支MV的自有图形函数、标志及桌面插画，旧视频和源码保留。字体来自本机Microsoft YaHei。

重制：

```powershell
py -3.11 promo/v2/render_mv.py --previews-only
py -3.11 promo/v2/render_mv.py
py -3.11 promo/v2/verify_mv.py
```

需要Python3.11、Pillow、NumPy、SciPy及PATH中的FFmpeg/FFprobe。输出只覆盖v2目录中的素材。`verify_mv.py`检验完整解码、音频信号、编码参数、开关/空档状态确实发生变化；最终视觉审查须打开编码后抽帧并记录，不代表应用真机验收。
