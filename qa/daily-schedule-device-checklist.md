# 1.3.1 每日模式真机验收（全部待执行）

工程测试通过不代表以下条目通过。当前无连接手机、无实机截图。每台目标机记录型号、Android版本、安装来源、APK哈希、系统后台策略、操作时间与结果；不得把单台通过写成全型号兼容。

- [ ] 旧版本原签名覆盖升级，首页为每日时段；原三分钟开关保持，未自动授予新权限。
- [ ] 开始/结束横排矩形框，点开为两组小时/分钟数字滚轮，不出现每日钟面选时。检查320dp小屏、横屏、大字体、读屏可操作且文字不遮挡。
- [ ] 添加至少3个分离时段，单独开启/关闭、修改和删除；保存后重开保留，取消不改变；删除须确认。关闭一段不影响其他段，09:00—12:00和14:00—18:00之间不拦截。
- [ ] 1.3.0旧计划升级后所有时间、总开关保持，原有时段默认为单段开启；单段关闭后重启应用仍为关闭，不会在旧边界拦截。
- [ ] 编辑弹窗中旋转屏幕或后台后重建，未保存的选择保留；相同起止保持弹窗并显示原因，不覆盖旧计划。
- [ ] 暂停全部保留每段开关；重新开启按各自状态执行。总开关开着但所有单段关闭时显示所有段已关，没有下一次禁用闹钟。
- [ ] 全程仅手机：添加计划、保存、阅读用途说明、启用无障碍。拒绝时显示待授权；撤权时显示服务不可用，不伪装拦截。
- [ ] 未开启设备管理员、没有电脑/ADB/设备所有者也能启用每日模式。
- [ ] 设开始为几分钟后、结束再几分钟后；返回普通应用，开始时自动拦截，结束时自动移除；连续重复两天不点开始。
- [ ] 22:00—次日07:00跨午夜，两个不相交时段、重叠和首尾相接正确；开始含、结束不含；相同起止被拒绝。
- [ ] 时段内打开桌面、短视频、游戏、浏览器、多窗口；记录覆盖效果及可绕过情况。覆盖页自身事件不导致闪烁或反复消失。
- [ ] 关屏、原系统锁屏、紧急呼叫正常；来电、接听、拨号、通话与挂断后回到普通应用时重新拦截。特别检查OEM独立来电界面。
- [ ] 系统设置、权限管理、无障碍关闭、应用内配置与卸载可操作；不覆盖授权对话框。第三方/OEM权限管理组件逐机确认。
- [ ] 设备休眠跨越开始/结束边界后唤醒/解锁按当前时段执行，不补过期拦截。
- [ ] 进程回收、系统恢复服务、重启后首次解锁、应用更新后计划保留；未启用计划不自动启用。
- [ ] 修改系统时间、时区；闹钟授权与撤销；无精确闹钟时提示延迟，已有可见覆盖页仍按当前时间撤下。
- [ ] 开关计划、编辑和删除立即重新计算；取消时间选择不修改旧计划；删除最后时段自动停用。
- [ ] 全日覆盖的并集不错误显示到期恢复；可用配置入口调整。
- [ ] 两种可选模式共存：三分钟息屏与每日计划各自开关；高级所有者专注优先，到期恢复每日计划。
- [ ] 强行停止、关闭权限、卸载确实可退出手机授权模式；用户提示与行为一致，没有“绝对强制”宣传。
- [ ] 无网络请求，无节点/内容获取；只使用窗口包名判断，包名不持久化；一小时电量与服务存活可接受。
