# 1.1.0自动息屏真机验收（待执行）

记录手机型号、Android版本、应用版本和时间。测试三分钟需保持亮屏：持续操作或临时将系统自动息屏调至至少10分钟，测试后恢复。应用不会保持常亮，也不会修改系统自动息屏设置。

| 场景 | 操作 | 预期 |
|---|---|---|
| 覆盖升级 | 从1.0.0安装1.1.0 | 可升级，旧提醒不再作为主流程，须授权锁屏后启用 |
| 权限拒绝 | 点击开启但取消设备管理器激活 | 不启动自动锁屏，明确提示未开启 |
| 权限范围 | 查看系统授权页 | 只申请锁屏，不含擦除数据/重置密码等 |
| 正常开启 | 同意激活，按需允许通知 | 后台检测开始，应用可显示开启状态 |
| 拒绝通知 | 授权锁屏但拒绝通知 | 自动息屏仍可工作，不被通知权限门槛阻断 |
| 立即测试 | 点击立即息屏测试 | 手机熄屏并锁屏；按系统规则解锁 |
| 180秒阈值 | 开始后在其他应用持续亮屏3分钟 | 之前无自动锁屏，约180秒时息屏；无需回到本应用 |
| 熄屏归零 | 2分50秒时熄屏，随后重新亮屏 | 从零再计3分钟才锁屏 |
| 再次亮屏 | 正式自动锁屏后重新亮屏 | 新一次完整3分钟计时，无锁屏连发 |
| 长熄屏 | 熄屏10分钟后亮屏 | 不补发锁屏，正常重新计时 |
| 停止 | 应用或状态通知中停止 | 无后续自动锁屏，重启不自动开启 |
| 撤销权限 | 运行中在系统设置撤销锁屏授权 | 自动检测停止并提示，不崩溃 |
| 解除授权与卸载 | 点击关闭并解除锁屏授权 | 服务停止、授权关闭，可按系统流程卸载 |
| 开机 | 开启后重启，首次解锁 | 自启动允许时恢复检测，否则用户可重开应用恢复 |
| 恢复应用 | 开启后因系统回收中止，重新打开 | 保留启用意图且仍有权限时重新启动；计时从恢复开始 |
| 后台长时间存活 | 锁屏/亮屏多轮，返回桌面至少30分钟 | 放行后台后仍按每次亮屏周期检测 |
| 不支持设备 | 无设备管理器功能的设备 | 无法开启且明确说明 |

当前无连接手机或可用模拟器。纯Java假系统适配器测试仅证明控制分支，不代表真实息屏、系统授权或后台行为已验收。
