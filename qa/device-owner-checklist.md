# 1.2.0设备所有者与定时专注真机验收（待设备）

记录型号、Android版本、系统构建、APK哈希、日期时间、执行人及ADB配置原始结果。先30秒，再长时段。保留纸质/另一台设备上的恢复码。

| 场景 | 检查 | 通过条件 |
|---|---|---|
| 未配置权限 | 普通安装打开管理页 | 显示尚未取得设备所有者，启动被禁用，不声称强制已生效 |
| 配置预检 | 有账号、多用户或其他管理者 | 工具停止，不删除、清空或绕过 |
| 成功配置 | 选定设备执行官方命令 | 原始成功输出且应用内isDeviceOwnerApp为真 |
| 结束权限 | 精确闹钟权限被拒绝 | 禁止启动，授权后可继续 |
| 30秒系统模式 | 开启测试 | 系统状态为LOCK_TASK_MODE_LOCKED，普通返回/主屏幕/任务切换不能提前离开 |
| 30秒到期 | 等待到时 | 自行解除限制、清理通知、恢复主屏幕及策略，无清空数据或改密 |
| 恢复码 | 先错码，再正确码 | 错码不解除，正确码可提前恢复；应用不重新显示明文 |
| 指定时刻 | 选择未来钟点 | 展示准确日期，确认后的等待时间正确 |
| 熄屏到期 | 熄屏覆盖结束时刻 | 到期解除策略，下次按原系统密码解锁后可正常使用 |
| 开机未解锁 | 专注中重启 | 设备加密状态可读取、重排到期；首次解锁后恢复专注或已到期则正常使用 |
| 专注内重启 | 剩余未到期重启并解锁 | 重新受系统强制专注约束，剩余时长不重置为完整时长 |
| 重启期间到期 | 关机跨过结束时间再启动 | 恢复执行时解除限制，无无限等待 |
| 调整时间 | 同次启动内通过测试环境改变墙上时钟 | 不提前结束、不无限延长，改变日期时间的普通设置被限制 |
| 中途回收进程 | 系统测试回收并返回主屏幕 | 临时HOME入口与持久状态恢复正确 |
| 电话与紧急呼叫 | 默认电话、来电、挂断、锁屏紧急入口 | 真实电话功能正常；结束电话回到专注；不开放娱乐应用 |
| 进入强制失败 | 模拟系统拒绝startLockTask | 取消任务并恢复策略，不退化为可退出屏幕固定却声称成功 |
| 分项恢复失败 | 可控测试环境拒绝一项恢复 | 其余项仍尝试恢复、保留快照与恢复错误，可重试完成 |
| 紧急解除管理 | 正确恢复码但策略恢复持续失败 | 验证后明确确认才能请求移除所有者，不能用错码或普通点击触发；移除失败不假报完成 |
| 主屏幕恢复 | 任务前后比较默认主屏幕和组件 | 仅专注期间接管HOME；结束后临时组件禁用，恢复用户原默认选择 |
| 普通息屏共存 | 原先开启/关闭三分钟息屏分别测试 | 专注期间暂停，结束后按原开关恢复 |
| 解除所有者 | 非专注时点解除管理 | 系统确认不再是所有者，可以正常卸载；专注中没有该入口 |

以上项目均未在手机执行。纯Java模型和构建检查不能代替此表。
